# The Marginal Player

Basketball analytics through the lens of economics — measuring what players are
worth, and where the market is wrong about them.

**https://johnfallon-econ.github.io/marginal-player/**

This repository holds only the generated site. It is published from a private
research repository and contains no source, no data files and no model code.

Every page is static and self-contained; there is no build step and no server.
